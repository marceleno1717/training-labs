# Lab 2
### 1) Clone the repo
```
git clone https://github.com/Ibrahim-Adel15/CalculatorGradleApp.git
```
### 2) run unit test
```
gradle test
```
Output
```

3 actionable tasks: 3 up-to-date
```
### 3) Build the app
```
gradle build
```
```

```

java -jar build/libs/calculator.jar
